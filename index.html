Category definitions

Each key is a theme (your keyword bucket); each value is either a boolean query or a plain list of terms. Queries support OR, AND, NOT, NEAR/3, parentheses, "quoted phrases", */? wildcards and #hashtags, and are matched against the words of each search term - so (vanilla OR caramel) NEAR/3 (perfume OR candle) NOT (recipe) behaves as written. Term lists keep the older forgiving substring matching (whole words for terms of 4 characters or fewer).

These options keep bare ingredient searches inside a theme. The first also accepts a product word, so "sandalwood candle" counts as Woody even though the definition only lists scent, fragrance, perfume, aroma, smell, bouquet and note. The second also accepts a search that is only notes and filler words, so "sandalwood" counts too - while "vanilla extract" and "rose garden" stay out. They only matter for queries written as term near context; plain term lists are unaffected.

Brand & product dictionary

Brands and formats are optional. Each key is a brand or a product type, and the value is a list of aliases matched against keywords the same way as terms. The bundled lists are a fragrance starter set; replace them with your own. Signature product names are included as aliases, so "santal 33" counts as Le Labo. Product types classify the format being searched for (candle, perfume, air freshener, wax melt).

When on, an unmatched search is attributed to a brand if one of its aliases is within one edit of a search word, and only when exactly one brand matches. Use it for messy exports; leave it off for clean data to avoid false positives.

Reading the output

Size is the sum of average monthly searches (AMS) for every keyword tagged with a theme - it is a scale signal, not a monthly volume. Short-term growth compares the latest month with the start of the short window (default 12 months). Long-term growth does the same over the long window (default 48 months). A theme with high growth but small size is an emerging niche; high growth plus large size is a genuine momentum shift. Themes and terms can overlap: one keyword can match several terms or themes, so shares can sum above 100% and term-level volumes are not mutually exclusive.

Method

Rows are tagged by testing each dictionary query or term against the keyword. A row joins a theme if any of that theme's terms match. Theme monthly volume is the sum of the row's monthly volumes; theme size is the sum of AMS. Growth is (latest - window start) / window start, using the last month in the data and the requested window length. This mirrors the "1Y Growth" and "4Y Growth%" columns in the manual workbook.
