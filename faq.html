Frequently asked questions

Short answers about what Open Trends does and how to use it.

App About

What is Open Trends?

A local browser app that turns Google Keyword Planner exports into theme-level trend analysis for any category. You provide the category searches and the keyword buckets (themes); it reports what is moving.

Is my data uploaded anywhere?

No. Everything runs in your browser. No data leaves your machine.

Is it free? Are there ads or tracking?

Yes, Open Trends is free and open source. There are no ads, no tracking and no accounts. You can inspect and self-host the code from GitHub.

Can I self-host it?

Yes. It is a fully static site. Run any static web server pointing at the folder, or use the included docker-compose.yml. See the README on GitHub for details.

What file formats are supported?

Google Keyword Planner exports as .xlsx, .xls or .csv, plus dictionary files as .json, .xlsx, .xls or .csv. The parser auto-detects the header row, so extra title rows are fine.

What columns does the export need?

A keyword column (Keyword, Query, Search term, ...), an AMS / average monthly searches column (optional - estimated from monthly values if missing), and monthly date columns (e.g. 2020-02-01, Feb-2020).

Can I analyse my own category?

Yes. Open Trends is category-agnostic. Upload your own theme dictionary under Category definitions (see example-categories.xlsx / .json) and re-run. The bundled example is just a demo.

What are brands and product types?

An optional second attribution dimension. Upload a brand dictionary and/or a product-type dictionary (or load the bundled sneakers starter set) under Brand & product dictionary to see which brands and formats (sneakers, boots, sandals, heels) drive each theme.

What do the context toggles do?

Treat product words as search context adds shoe/product words to NEAR queries so searches like "running shoe" still match. Also match bare descriptor searches also accepts searches that are only descriptors and filler words, like "running". They only affect queries written as descriptor near context; plain term lists are unaffected.

Can I use an LLM to build my dictionaries?

Yes. Paste a sample of your Keyword Planner keywords (or a category description) into any LLM and ask for theme names with Boolean queries or term lists, plus brand aliases and product types. Request JSON in the app's dictionary shape or CSV/XLSX with Theme/Query columns, then paste or upload and Apply dictionary.

What format should an LLM produce?

Themes: an object keyed by theme name, value either a query string ((running OR jogging) NEAR/3 (shoe OR sneakers)) or an array of terms. Brands/product types: an object keyed by name, value an array of alias strings. CSV/XLSX equivalents use Theme, Query (or Brand, Aliases) columns.

How do themes work?

Each theme is either a Boolean query (OR, AND, NOT, NEAR/n, parentheses, "phrases", * / ? wildcards, #hashtags) or a plain list of terms. Queries match against the words of each search term. Term lists use forgiving substring matching.

Why are most searches "unclassified"?

The bundled example only classifies a search when it names a shoe type or product (e.g. running shoes, boots). Most of a Keyword Planner export does not. That is a property of the definitions and the export, not a parsing failure. The Coverage card on the Overview tab and the unclassified CSV show what was left out and why.

Can themes overlap?

Yes. One keyword can match several themes and terms, so shares can sum above 100% and term-level volumes are not mutually exclusive. Only keyword-level tables are additive.

What do "short-term" and "long-term" growth mean?

Short-term growth compares the latest month with the start of the short window (default 12 months). Long-term growth does the same over the long window (default 48 months). Formula: (latest - window start) / window start.

What is the seasonality index?

Average volume for a calendar month divided by the average month for that theme, times 100. 100 = an average month.

How do I export results?

Use Export → Download full Excel workbook for a multi-sheet workbook, or the individual CSV/JSON buttons. The workbook includes Summary, Theme Growth, Term Growth, drivers, brands, product types, top searches, seasonality, monthly volumes and classification.

Which browsers are supported?

Modern Chrome or Edge. The app uses local file parsing and Chart.js; open index.html directly or self-host with any static server (docker-compose included).

Where can I get help or report an issue?

Open an issue on GitHub, or connect on LinkedIn. For how the tool works in depth, see the README in the repository.
